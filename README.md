# Лабораторная работа 2

Анализ успеваемости на JavaScript. Индивидуальное выполнение задания с демонстрацией веток и Pull Request в GitHub.

## Запуск

```sh
node main.js
node analysis.test.js
```

Внешние зависимости не нужны. Используются модули ES.

## Файлы

- `grades.js` — исходные данные из задания.
- `analysis.js` — четыре функции анализа.
- `main.js` — вызов функций и вывод результата.
- `analysis.test.js` — 13 проверок результатов и граничных случаев.

## Результат

Средний балл — 77.6; лучший студент — Денис; должник при пороге 60 — Студент_X.
Буквенные оценки: Макар B, Денис A, Анна B, Даша B, Студент_X C.

Для пустого массива средний балл и лучший студент равны `null`; остальные функции возвращают `[]`. При равенстве максимальных баллов выбирается первый студент. Функции не изменяют исходные данные.

## Git

Рабочая ветка `feature/anton` создаётся от `develop`. Изменения интегрируются через Pull Request в `develop`, затем через Pull Request в `main`. Работа выполнена одним автором; независимое командное ревью не заявляется.
